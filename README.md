California Housing Price Prediction

Project Overview

This project predicts California housing prices using Machine Learning. It provides a way to estimate house prices based on housing-related input features.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- FastAPI
- HTML and CSS
- Joblib / Pickle

Project Features

- Machine Learning model for housing price prediction
- Web interface for entering housing features
- Flask-based prediction application
- FastAPI-based prediction application
- Model loading and prediction using a trained model

Project Structure

The project includes model training code, Flask and FastAPI applications, trained model files, HTML templates, and CSS files.

Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Move into the project folder:

cd California-Housing-ML

Install dependencies:

pip install -r requirements.txt

How to Run

Run the Flask or FastAPI application separately, according to the corresponding Python file and its configuration.

Example for FastAPI:

uvicorn fast_app:app --reload

Open the API documentation at "http://127.0.0.1:8000/docs" when the FastAPI application is running.

Learning Outcomes

- Data preprocessing
- Machine Learning model training
- Model serialization and loading
- Building prediction APIs
- Developing web applications using Flask and FastAPI
